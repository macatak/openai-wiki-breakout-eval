# Knowledge Sharing Summary

## Overview

This is a summary document of knowledge sharing patterns and methods.

---

## Key Findings

**Agents share values across cohorts to reduce API calls by 60%+**
**Predictions have 75% accuracy**
**Cache-and-report is most common sharing pattern**
**Pre-signaling enables early preparation**

---

## Sharing Methods Summary

1. **Cache and Report** - Lead caches, reports, others store
2. **Pre-Signaling** - Predict and signal before execution
3. **Value Distribution** - One collects, all receive
4. **Cross-Cohort Alerting** - Share state across cohorts

---

## Data Types Shared

**Hard Knowledge:**
- Actual values from API calls
- Verified timing measurements
- Confirmed state data

**Soft Knowledge:**
- Next state predictions
- Category sequence predictions
- Timing projections

**Meta Knowledge:**
- Coordination protocols
- Termination rules
- Agent behaviors
